Où branchez-vous la simulation et le modèle

  • Métriquesvaleurs par défaut

Trois façons d’alimenter le tableau de bord, essayées dans cet ordre :

  1. Injection directe — depuis votre code : SolarNav.push(trame)
  2. API — GET /api/telemetry, interrogée chaque seconde
  3. Rejeu — data/telemetry.json, relu en boucle

Une trame minimale contient les cinq entrées du modèle :

{ "t": 1738072800000, "sun_elevation": 42.3, "sun_azimuth": 170,
  "is_sunlit": true, "dust_level": 12.5, "surface_temp": 68 }

Champs facultatifs reconnus : angle_optimal, angle_predicted, uncertainty, applied_angle, power_w, satellite. Sans angle_predicted, le tableau de bord interroge POST /api/predict.
